## **3. Multiple Devices -> Switch -> Switch**

**Problem**
- If one switch connects all devices in a growing network, the available ports become limited and managing and expanding the network becomes difficult.
- To solve this, we add another switch and connect both switches while keeping all devices in the same LAN.

**Devices**
- 4 PCs
- 4 Laptops
- 2 Switches (2960)

**Connection**
- PC0 Fa0 -> Switch0 Fa0/1
- Laptop0 Fa0 -> Switch0 Fa0/2
- PC1 Fa0 -> Switch0 Fa0/3
- Laptop1 Fa0 -> Switch0 Fa0/4
- PC2 Fa0 -> Switch1 Fa0/1
- Laptop2 Fa0 -> Switch1 Fa0/2
- PC3 Fa0 -> Switch1 Fa0/3
- Laptop3 Fa0 -> Switch1 Fa0/4
- Switch0 Fa0/24 -> Switch1 Fa0/24
- Use Copper Straight-Through cables for end devices.
- Use Copper Cross-Over cable between the switches.

**PC configuration**
- PC0 -> `192.168.1.10`
- Laptop0 -> `192.168.1.11`
- PC1 -> `192.168.1.12`
- Laptop1 -> `192.168.1.13`
- PC2 -> `192.168.1.20`
- Laptop2 -> `192.168.1.21`
- PC3 -> `192.168.1.22`
- Laptop3 -> `192.168.1.23`
- Subnet Mask -> `255.255.255.0`

**Switch configuration**
- Switch0 VLAN 1 -> `192.168.1.10`
- Switch1 VLAN 1 -> `192.168.1.20`

**Failure Cases**
- Switch-to-switch link disconnected -> Devices connected to different switches cannot communicate with each other.
- Different VLAN -> Devices are logically separated even though they are connected through the same physical network.

**Troubleshooting**
- Check the switch-to-switch connection
- Check both switch port statuses: `show interfaces status`
- Check MAC address tables: `show mac address-table`
- Check VLAN configuration: `show vlan brief`

**Result**
- Multiple switches extend the same LAN, allowing more devices to connect while improving scalability and making the network easier to manage.
- Devices connected to both switches can communicate using MAC addresses.
